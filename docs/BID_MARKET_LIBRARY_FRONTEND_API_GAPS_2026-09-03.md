# 投标行情内容库前端接口缺口

核对日期：2026-09-03

当前后端的历史报价接口提供结构化价格样本，通用文件接口提供文件存储，但两者都不是文章、视频和文档组成的投标行情内容库。前端当前不以静态数据冒充接口结果，也不会请求推测出来的路径。

前端仍需后端提供以下能力：

- 内容列表与搜索：支持关键词、内容类型、分类、分页与总数。
- 内容分类：支持公众号文章、公众号视频、文档、其他四类，并返回各类内容数量。
- 内容详情：统一返回标题、摘要、来源、发布时间、类型、分类和可预览内容标识。
- 内容预览：按内容类型返回正文、文档预览或视频播放所需数据。
- 内容上传入库：支持文章、视频和文档上传，并关联后端真实分类。
- URL 导入入库：接收公开 HTTP/HTTPS 地址和所选分类，由后端下载、解析并持久化文章或视频内容。
- 内容删除：按内容 ID 删除行情资料，并返回可供列表立即同步的删除结果。
- 管理权限：由后端账号预设并在用户信息接口的 `permissions` 中返回；上传和删除能力统一使用 `admin.user` 权限控制，普通账号不可见。

开发联调说明：本地 `backend` 模式可通过未提交到版本库的 `VITE_DEV_ADMIN_EMAILS` 白名单临时检查管理员界面；该白名单仅在 `import.meta.env.DEV` 下生效，不能替代正式环境的后端鉴权。

在接口提供前，上述能力仅在 API 调试面板标记为“后端未提供”，均不参与运行时请求捕获。
